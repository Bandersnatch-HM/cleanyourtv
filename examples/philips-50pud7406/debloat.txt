# QUIRKS ON THIS FIRMWARE:
#
# 1. Screensaver. screensaver_components ships as com.google.android.backdrop/.Backdrop with a
#    5-minute screen_off_timeout. Once backdrop is disabled the screensaver points at a disabled
#    component, so set another one:
#      settings put secure screensaver_components com.gathin.tvhome/.ClockDream
#      settings put secure screensaver_default_component com.gathin.tvhome/.ClockDream
#    (or com.android.dreams.basic/.Colors without the launcher).
# 2. Chromecast on a shared network. On this owner's Wi-Fi (a large shared network, ~150 hosts
#    across 192.168.1-18.x) about 150 devices held connections to the TV's Cast port 8009, and
#    YouTube kept pausing and then closing a few minutes into a video. The log showed the exit:
#      ActivityTaskManager: START u0 {act=MAIN cat=[HOME] ...} from uid 10043
#    uid 10043 is com.google.android.apps.mediashell. Disabling it fixed playback. Unlike the
#    50PUS8517 (its quirk 4), mediashell stayed disabled here 45 s after disabling; a reboot
#    check is still pending. Keep it (comment the line out) if you cast from your phone and your
#    network is your own.
# 3. lowmemorykiller is active even at idle with one app playing ("low watermark is breached and
#    thrashing"); this is a 1.38 GB low_ram set, so every background service removed helps.
# 4. Do not open com.mediatek.tv.factory or mediatek.factorymenu.ui to see what they do (see
#    PROMPT.md); they are left alone.

# COLOMBIA UNIT (55PUT7906/57, Spanish UI). Lived with for two days, reboot-checked: every package
# below that is not commented out stays disabled. Home was Free My TV, not launcher/, which turns off
# tvlauncher, tvrecommendations, play.games, youtube.tvmusic and the retail demo itself. The owner kept
# mediashell (Chromecast, own network), Netflix, Prime Video and katniss. org.droidtv.nettvregistration
# was disabled here: one "Scheduling restart of crashed service" per service, then quiet, across reboots,
# but no firmware update has been offered since, so it stays commented out below. eum was kept.
# The packages marked "Colombia unit" below were added from this TV. Private DNS works.
# What else this unit showed:
# - com.android.tv.settings/.device.privacy.PrivacyActivity is the FACTORY RESET screen on this
#   firmware, not privacy. Do not start settings activities by name to find a page.
# - Every volume change was spoken in English ("volume change X percent") by com.mediatek.tv.freeviewplay
#   (UK Freeview Play, via Google TTS), with accessibility off and no switch for it in any menu. It is a
#   persistent package, so its process still starts after `pm disable-user`, but after a reboot it no
#   longer speaks. Live TV (tvcenter binds its FreeviewPlayManagerService) still works.
# - The remote's Google Play button is IR scan 127 with no key code: TPVTvService consumes it and opens
#   com.google.android.videos (Play Movies, shut down in Dec 2023), per the read-only
#   /vendor/etc/hot-key-info.ini. No key filter sees it; TPVTvService logs each press
#   ("KeyCode=0,scan=127"), which an app granted READ_LOGS can follow. Netflix is key code 265; YouTube
#   and Prime are both 249 (scan 123 and 470).
# - The default keyboard goes back to com.google.android.tv.remote.service/.ImeBridgeService at every
#   boot when the chosen one is a downloaded app (LeanKeyboard here). Play Store updates of Gboard (17.x)
#   broke typing on this build; the factory 11.0.02 works.
# - `screencap -p` to stdout starts with a text line ("Init wrapper sys mutex successful...") before
#   the PNG; strip everything before PNG.
# - persist.odm.tpv.sys.ACR_Avail is 0 for Colombia; the ACR code lives inside TPVTvService, not a package.
