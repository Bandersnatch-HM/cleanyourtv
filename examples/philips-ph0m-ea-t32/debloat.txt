# QUIRKS ON THIS FIRMWARE:
#
# 1. com.android.tv.settings/.device.privacy.PrivacyActivity is the FACTORY RESET screen here, not
#    privacy. Do not start settings activities by name to find a page. Usage & diagnostics is under
#    Device Preferences; the ad ID page is the com.google.android.gms.settings.ADS_PRIVACY action
#    (a phone-style page: the focus is invisible, so use uiautomator dump + input tap).
# 2. `screencap -p` on stdout starts with a text line ("Init wrapper sys mutex successful...")
#    before the PNG. Strip everything before \x89PNG.
# 3. The Wi-Fi saved during setup belongs to setupwraith: keep it enabled (or forget and re-join
#    the network first). Free My TV's switch refuses to run until the network is re-joined.
# 4. The default keyboard resets at every boot to com.google.android.tv.remote.service/.ImeBridgeService
#    when the chosen one lives in /data (LeanKeyboard here): Android picks a direct-boot-aware IME
#    before the user unlocks. Something has to set it back after boot. Play Store updates of Gboard
#    (17.x) broke the keyboard on this Android 11 build; the factory 11.0.02 works.
# 5. Remote: Netflix=KEYCODE 265, YouTube=249 (scan 123), Prime=249 (scan 470). The Google Play
#    button is IR scan 127 (KEY_COMPOSE) with no key code: TPVTvService consumes it before any key
#    filter and opens com.google.android.videos (Play Movies, shut down by Google in Dec 2023, it only
#    redirects to the stock launcher's Shop tab), per the read-only /vendor/etc/hot-key-info.ini.
#    TPVTvService logs every press ("LogKeyPressEvent: KeyCode=0,scan=127"), which an app holding
#    READ_LOGS (pm grant) can follow to open something else.
# 6. TPVTvService also logs every key press as "usagelogger"; its upload target (NetTV logger) is
#    gone with nettvregistration disabled. The firmware carries Alphonso/Samba ACR support inside
#    TPVTvService, not as a package: persist.odm.tpv.sys.ACR_Avail is 0 for Colombia.
# 7. Every volume change was spoken in English ("volume change X percent") by com.mediatek.tv.freeviewplay
#    (UK Freeview Play, TTSManagerImpl2 -> Google TTS), even with accessibility off and no menu switch for
#    it anywhere (Android Accessibility, the Live TV menu, Sound). The package is PERSISTENT, so its process
#    still starts after `pm disable-user`, but once disabled and rebooted it no longer speaks. Live TV
#    (tvcenter, which binds its FreeviewPlayManagerService) still works. Reboot-checked.
# 8. Disabling nettvregistration logs one "Scheduling restart of crashed service" per service and
#    then stays quiet; nothing crash-loops. Reboot-checked: every package below stays disabled.
#
# Settings also changed on this set (not packages): AdGuard Private DNS (dns.adguard-dns.com),
# animation scales 0.5, advertising ID deleted, Usage & diagnostics off.
